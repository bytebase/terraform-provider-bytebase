# Migrate from 3.22.1 to 3.23.0

No state migration is required.

## New features

### Generic OIDC workload identities

`bytebase_workload_identity.workload_identity_config.provider_type` now accepts `OIDC` for workload identity providers other than GitHub and GitLab. Use the optional `jwks_url` when the issuer does not publish a discovery document; otherwise Bytebase discovers the JWKS endpoint from `issuer_url`.

```hcl
resource "bytebase_workload_identity" "generic_oidc_ci" {
  workload_identity_id = "generic-oidc-ci"
  title                = "Generic OIDC CI"

  workload_identity_config {
    provider_type     = "OIDC"
    issuer_url        = "https://issuer.example.com"
    jwks_url          = "https://issuer.example.com/.well-known/jwks.json"
    allowed_audiences = ["bytebase"]
    subject_pattern   = "sub:ci:deploy"
  }
}
```

### Workload identity authentication

The provider can exchange an external OIDC token for a short-lived Bytebase access token. Before using this mode, an administrator must create the workload identity, configure its issuer, audience, and subject restrictions, and grant it the required IAM roles.

Configure exactly one authentication mode:

- `service_account` with `service_key`; or
- `workload_identity_email` with exactly one of `workload_identity_token` and `workload_identity_token_file`.

For workloads whose OIDC token is rotated on disk, use `workload_identity_token_file`. The provider rereads the file when Bytebase authentication expires, exchanges the replacement token, and retries the failed request once.

```hcl
provider "bytebase" {
  url                          = "https://bytebase.example.com"
  workload_identity_email      = "terraform@workload.bytebase.com"
  workload_identity_token_file = "/secrets/bytebase.jwt"
}
```

The equivalent environment variables are:

- `BYTEBASE_WORKLOAD_IDENTITY_EMAIL`
- `BYTEBASE_WORKLOAD_IDENTITY_TOKEN`
- `BYTEBASE_WORKLOAD_IDENTITY_TOKEN_FILE`

Remove `BYTEBASE_SERVICE_ACCOUNT` and `BYTEBASE_SERVICE_KEY` when switching modes. Keep external OIDC tokens and returned Bytebase access tokens out of Terraform configuration, state, and logs.
