# Migrate from 3.20.4 to 3.21.0

No state migration is required.

## Features

### Google database instance identifiers

`bytebase_instance.data_sources` now supports explicit Google resource identifiers for Spanner and BigQuery:

- `project_id` is available for `SPANNER` and `BIGQUERY`.
- `instance_id` is available for `SPANNER`.

Use these fields instead of overloading `host` with Google resource IDs:

```hcl
resource "bytebase_instance" "spanner" {
  # ...
  engine = "SPANNER"

  data_sources {
    id          = "admin"
    type        = "ADMIN"
    project_id  = "my-project"
    instance_id = "my-instance"
    database    = "my-database"
  }
}
```

### Vault external-secret TLS configuration

`bytebase_instance.data_sources.external_secret.vault` now supports TLS configuration for Bytebase connections to HashiCorp Vault:

- `vault_ssl_ca`
- `vault_ssl_cert`
- `vault_ssl_key`
- `skip_vault_tls_verification`

The inline PEM fields are sensitive and input-only. Keep them in Terraform configuration, variables, or your secret manager so Terraform can preserve them across refresh and update when the Bytebase API omits the raw values on read.

```hcl
resource "bytebase_instance" "postgres_vault" {
  # ...

  data_sources {
    external_secret {
      vault {
        url                         = "https://vault.example.com:8200"
        token                       = var.vault_token
        engine_name                 = "secret"
        secret_name                 = "database/postgres"
        password_key_name           = "password"
        vault_ssl_ca                = file("${path.module}/certs/vault-ca.pem")
        vault_ssl_cert              = file("${path.module}/certs/vault-client-cert.pem")
        vault_ssl_key               = file("${path.module}/certs/vault-client-key.pem")
        skip_vault_tls_verification = false
      }
    }
  }
}
```

## Breaking changes

### `SQLITE` engine removed

`SQLITE` is no longer an accepted value for `bytebase_instance.engine`. Remove or migrate any Terraform-managed SQLite instances before upgrading to this provider version.
